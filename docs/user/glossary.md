# Glossary

For: people who use the Obsidian plugin. For the server's terms, admins can read the admin glossary.

**Conflict copy.** A second file that vault-sync makes when two devices changed the same file and the changes cannot be combined. It holds the other version. See [Conflicts and history](conflicts-and-history.md).

**Conflict view.** A sidebar that lists your conflict copies and the files that do not sync. Open it with **Vault Sync: Show conflicts**.

**Config folder.** The folder where Obsidian keeps settings, themes and plugins, usually `.obsidian`. vault-sync does not sync it.

**Device.** One copy of the plugin, in one Obsidian vault, on one computer or phone. See [Devices](devices.md).

**Editor.** A member who can read and change notes. See [Sharing](sharing.md#roles).

**End-to-end encryption.** Your devices encrypt files before upload and decrypt them after download, so the server cannot read them. See [Encryption](encryption.md).

**Escrow.** An option for an encrypted vault that lets your admin's backup read it, and restore it if every member forgets their passphrase. See [Encryption](encryption.md#escrow).

**Fingerprint.** A short code that identifies a key. Members compare fingerprints to make sure that they hold the same keys.

**History.** The older versions of a file that the server keeps. See [Conflicts and history](conflicts-and-history.md#history).

**Invite code.** A code that an owner gives you to join a vault. It works once.

**Owner.** A member who can change notes, manage members and invitations, and delete the vault.

**Plaintext vault.** A vault without end-to-end encryption.

**Recovery passphrase.** The passphrase that unlocks your encryption key on a new device. Nobody can recover it for you.

**Remote vault.** The server vault that your Obsidian vault syncs with.

**Rotate key.** For an owner: give an encrypted vault a new key, so that new changes use it.

**Viewer.** A member who reads only.

**Vault.** In Obsidian, a folder of notes. On the server, the shared copy that your Obsidian vault syncs with.
