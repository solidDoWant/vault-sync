# Changelog

All notable changes to vault-sync are listed here, newest release first.

## 0.3.0

The first public release. It covers Phase 1 (foundations), Phase 2 (single-user file sync) and Phase 3 (vault sharing); there is no separate 0.2.0. Install the server image `ghcr.io/soliddowant/vault-sync:0.3.0` or the Helm chart, and the plugin through BRAT from this repository's GitHub releases.
